# 08. 报告页

请先阅读：

- `AGENTS.md`
- `docs/03-design-system.md`
- `docs/06-page-acceptance.md`
- `docs/07-interaction-rules.md`
- 当前已有组件和 store

任务文件：`src/pages/report/index.vue`


实现报告页。

页面目标：让用户第一眼看清每天至少要做到多少。

首屏必须包含绿色结论卡：

- 最大数字：日流水目标
- 辅助：约 X 单
- 回本周期
- 一句经营解释

必须展示指标：

- 月流水目标
- 日流水目标
- 日单量目标
- 客单价
- 毛利率
- 回本周期

必须展示风险评估：

- 固定成本压力
- 单量压力
- 回本周期压力
- 毛利率合理性

必须展示 3 条经营优先级建议。

交互：

- 保存模型并进入看板。
- 修改参数。
- 去实验室模拟优化。
- 点击核心指标可展开公式说明。

空状态：

- 没有 shopModel 时，引导用户去完成测算。

视觉：

- 参考设计图中的报告页。
- 最大数字必须突出。
- 不要把所有指标做成一样大。


通用要求：

1. 必须复用已有基础组件和业务组件。
2. 不新增未定义颜色。
3. 不新增 V1 范围外功能。
4. 不直接读写 storage。
5. 不在页面中写复杂公式。
6. 完成后按 `docs/06-page-acceptance.md` 自查。
7. 输出修改文件列表和本地验证方式。
