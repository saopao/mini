# 05. 欢迎页

请先阅读：

- `AGENTS.md`
- `docs/03-design-system.md`
- `docs/06-page-acceptance.md`
- `docs/07-interaction-rules.md`
- 当前已有组件和 store

任务文件：`src/pages/welcome/index.vue`


实现欢迎页。

页面目标：让用户理解产品价值并开始测算。

必须包含：

- 标题：开店避坑助手
- 副标题：开店前先算清，开店后每天看清
- 中部绿色店铺插画或占位视觉
- 主按钮：开始测算
- 次按钮：我已开店，直接进入
- 底部说明：数据默认保存在本地，保护你的经营隐私

交互：

- 点击开始测算进入行业选择页。
- 点击我已开店进入行业选择页，并设置状态为 opened。
- 不出现登录拦截。

视觉：

- 参考 `reference/design-reference-v1.png` 第一屏气质。
- 背景可使用浅绿氛围。
- 主按钮深绿实心。
- 不要堆复杂说明。


通用要求：

1. 必须复用已有基础组件和业务组件。
2. 不新增未定义颜色。
3. 不新增 V1 范围外功能。
4. 不直接读写 storage。
5. 不在页面中写复杂公式。
6. 完成后按 `docs/06-page-acceptance.md` 自查。
7. 输出修改文件列表和本地验证方式。
