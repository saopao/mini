# 15. 全链路回归

请先阅读：

- `AGENTS.md`
- `docs/06-page-acceptance.md`
- `docs/10-test-cases.md`
- `docs/11-launch-checklist.md`

任务：

对当前项目做全链路回归检查。先不要改代码，先输出问题清单。

必须检查的用户路径：

```txt
首次打开
→ 欢迎页
→ 开始测算
→ 行业选择页
→ 选择奶茶/饮品
→ 建模页
→ 输入参数
→ 生成报告
→ 报告页
→ 保存模型并进入看板
→ 看板页
→ 记一笔收入 200
→ 看板刷新
→ 记一笔支出 120
→ 看板刷新
→ 实验室页
→ 提高客单价
→ 查看前后对比
→ 我的页
→ 修改模型
→ 报告/看板/实验室同步刷新
→ 清空本地数据
→ 回到欢迎页
```

必须检查：

1. 页面是否都能进入。
2. 路由是否正确。
3. tabBar 是否只有 4 项。
4. 本地数据是否持久化。
5. 修改模型是否联动。
6. 删除记录是否联动。
7. 所有空状态是否存在。
8. 所有危险操作是否二次确认。
9. 所有核心公式是否正确。
10. 是否出现 V1 范围外功能。
11. 是否违反设计系统。
12. 是否有明显真机兼容风险。

输出格式：

```md
# 全链路回归报告

## 结论
- 是否可进入内测：是/否

## P0 必须修复
- xxx

## P1 建议修复
- xxx

## P2 可后置
- xxx

## 已通过项
- xxx

## 需要用户确认
- xxx
```

如果发现问题，先列清单，不要直接大范围修改。
