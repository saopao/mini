# 07. 建模页

请先阅读：

- `AGENTS.md`
- `docs/03-design-system.md`
- `docs/06-page-acceptance.md`
- `docs/07-interaction-rules.md`
- 当前已有组件和 store

任务文件：`src/pages/calculate/index.vue`


实现建模页。

页面目标：填写经营参数并生成报告。

必填字段：

- 前期投入
- 每月固定支出
- 每月营业天数
- 行业毛利率
- 客单价
- 回本周期

可选字段：

- 店铺名称
- 城市
- 最大日接待单量

必须实现：

- 表单校验。
- 行业默认值带入。
- 底部即时预估条。
- 点击生成经营报告后进入报告页。
- 有未保存输入离开时确认。

即时预估条展示：

- 预计月流水目标
- 预计日流水目标
- 预计日单量目标

校验：

- 前期投入 > 0
- 固定支出 >= 0
- 营业天数 1-31
- 毛利率 1%-95%
- 回本周期 1-60 月
- 客单价 > 0

不得在页面内直接写公式，必须调用 calculator service。


通用要求：

1. 必须复用已有基础组件和业务组件。
2. 不新增未定义颜色。
3. 不新增 V1 范围外功能。
4. 不直接读写 storage。
5. 不在页面中写复杂公式。
6. 完成后按 `docs/06-page-acceptance.md` 自查。
7. 输出修改文件列表和本地验证方式。
