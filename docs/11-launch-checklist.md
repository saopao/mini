# 内测与上线前检查清单

## 使用方式

本清单用于进入内测或上线前。没有代码工程时不执行，只作为后续质量闸门。

## 产品范围检查

- [ ] V1 只包含欢迎、行业选择、开店测算、经营报告、看板、记账、实验室、我的。
- [ ] 没有实现登录，除非用户后续明确要求。
- [ ] 没有实现支付。
- [ ] 没有实现会员。
- [ ] 没有实现库存。
- [ ] 没有实现员工管理。
- [ ] 没有实现自动对账。
- [ ] 没有实现多店铺。
- [ ] 没有实现面向用户的不透明 AI 经营承诺。

## 视觉检查

- [ ] 所有页面主色一致。
- [ ] 所有卡片圆角一致。
- [ ] 所有按钮样式一致。
- [ ] 没有随机颜色。
- [ ] 没有重阴影。
- [ ] 每页只有一个最大视觉焦点。
- [ ] 与 `reference/design-reference.png` 气质一致。
- [ ] 320px、375px、414px 宽度均无文字重叠。
- [ ] 底部按钮和 Tab 适配安全区。

## 公式检查

- [ ] 每月目标利润公式正确。
- [ ] 月毛利目标公式正确。
- [ ] 月流水目标公式正确。
- [ ] 日流水目标公式正确。
- [ ] 日单量目标公式正确。
- [ ] 日固定成本摊销公式正确。
- [ ] 今日估算利润公式正确。
- [ ] 回本进度公式正确。
- [ ] 边界值不会返回 NaN 或 Infinity。
- [ ] 设计稿样例值和公式值不一致时，以文档公式为准，并有解释。

## 页面检查

### 欢迎页

- [ ] 能进入行业选择。
- [ ] 文案简洁。
- [ ] 隐私说明存在。
- [ ] 免责声明入口存在。

### 行业选择页

- [ ] 行业卡片能选中。
- [ ] 选中状态明显。
- [ ] 行业默认值能带入测算页。
- [ ] 未选择行业不能进入下一步。

### 开店测算页

- [ ] 必填字段完整。
- [ ] 校验明确。
- [ ] 即时预估正常。
- [ ] 能生成报告。
- [ ] 离开未保存表单有提示。

### 经营报告页

- [ ] 第一屏能看到日流水目标。
- [ ] 核心指标可解释。
- [ ] 风险评估存在。
- [ ] 经营建议存在。
- [ ] 能保存模型并进入看板。
- [ ] 免责声明可见。

### 今日看板页

- [ ] 今日状态正确。
- [ ] 今日利润正确。
- [ ] 完成率正确。
- [ ] 最近记录正确。
- [ ] 无记录有引导。
- [ ] 无模型不展示无意义 0 目标。

### 快速记账页

- [ ] 10 秒内可完成记录。
- [ ] 收入/支出切换正常。
- [ ] 快捷金额正常。
- [ ] 保存后反馈正确。
- [ ] 编辑和删除记录后聚合刷新。

### 实验室页

- [ ] 调整变量实时刷新。
- [ ] 前后对比清楚。
- [ ] 建议文案合理。
- [ ] 不保存返回时不覆盖当前模型。

### 我的页

- [ ] 当前模型显示正确。
- [ ] 修改模型可进入测算或编辑流程。
- [ ] 清空数据有二次确认。
- [ ] 免责声明可查看。
- [ ] 数据说明可查看。

## 小程序体验检查

- [ ] 顶部安全区正常。
- [ ] TabBar 正常。
- [ ] 底部按钮不被遮挡。
- [ ] 键盘不遮挡核心输入。
- [ ] 页面返回路径清晰。
- [ ] 没有横向滚动。
- [ ] 真机滚动流畅。
- [ ] 网络不可用时本地核心能力仍可用。

## 数据检查

- [ ] 保存模型后杀进程重开不丢失。
- [ ] 保存记录后杀进程重开不丢失。
- [ ] 修改模型后报告、看板、实验室同步刷新。
- [ ] 删除记录后趋势和累计利润同步回滚。
- [ ] 清空数据后所有状态重置。
- [ ] 本地存储异常有恢复入口。

## 文案检查

- [ ] 没有“包回本”。
- [ ] 没有“稳赚”。
- [ ] 没有“保证收益”。
- [ ] 没有“无风险开店”。
- [ ] 风险提示不恐吓。
- [ ] 经营建议听得懂。
- [ ] 免责声明存在。

## 埋点检查

- [ ] `welcome_view`
- [ ] `industry_select`
- [ ] `calculate_submit`

- [ ] `store_create`
- [ ] `dashboard_view`

- [ ] `ledger_entry_create`

## 内测进入标准

- [ ] 全链路跑通。
- [ ] 核心页面截图评分 >= 90。
- [ ] 公式测试全部通过。
- [ ] 真机无 P0/P1 问题。
- [ ] 至少 10 个真实或接近真实的参数样本跑通。
- [ ] 所有免责声明和删除路径明确。

## 内测观察指标

- 首次建模完成率。
- 报告页保存率。
- 首次记账转化率。
- 7 天内 3 次记录比例。
- 实验室使用率。
- 用户是否能复述“每天至少要卖多少”。
