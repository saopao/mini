# 交互规则

## 交互原则

1. 先给结论，再给解释。
2. 先降低输入压力，再逐步补充细节。
3. 所有数据变化都要即时反馈。
4. 风险提示要可理解，不制造恐慌。
5. 任何经营建议都必须有可追溯的输入或公式。
6. 用户未登录也能完成 V1 核心闭环。

## 导航规则

### 首次使用

```text
欢迎页 -> 行业选择页 -> 开店测算页 -> 经营报告页 -> 今日看板页
```

规则：

- 未完成测算前，不直接进入日常看板。
- 如果用户点击“直接进入”，但没有模型，应提示“先完成一次测算，今日目标才有意义”。
- 完成报告保存后，将看板设为默认首页。

### 日常使用

```text
看板 <-> 快速记账弹窗
看板 <-> 记录 Tab
看板 <-> 实验室
我的页 -> 修改模型 -> 经营报告 -> 看板
```

规则：

- 看板是老用户默认入口，默认进入今日视图。
- 看板可切换今日、本周、本月。本周按周一到周日自然周，本月按自然月；周/月目标按完整周期目标展示。
- 记账保存后可留在弹窗继续录入，也可返回看板。
- 快速记账主流程按“收入/支出和日期确认 -> 页面内数字键盘输入金额 -> 选择分类/备注 -> 确定”组织。
- 记账金额不得依赖系统键盘；用户应能直接点击页面内数字键盘完成输入和保存。
- 快速记账使用公共弹窗承载新增和当前编辑；历史筛选、分页、删除进入记录 Tab。
- 实验室不改变当前模型，除非用户明确保存方案或采纳修改。

## 数据保存规则

V1 默认本地优先。

需要持久化的数据：

- 当前模型。
- 当前行业模板。
- 经营报告快照。
- 记账记录。
- 实验室最近一次调整值。
- 用户已读免责声明状态。

保存时机：

- 经营报告点击保存后写入当前模型。
- 记账点击保存后写入记录。
- 修改模型确认保存后覆盖当前模型，并重算报告。
- 清空数据必须二次确认后执行。

不应自动保存的内容：

- 未提交的无效表单值。
- 实验室临时推演结果。
- 用户未确认的行业切换。

## 表单校验规则

| 字段 | 规则 | 失败提示 |
|---|---|---|
| 前期投入 | 必填，> 0，最多两位小数 | 请输入大于 0 的前期投入 |
| 每月固定支出 | 必填，>= 0，最多两位小数 | 请输入有效的每月固定支出 |
| 每月营业天数 | 必填，1-31 的整数 | 营业天数应在 1-31 天之间 |
| 行业毛利率 | 必填，1%-95% | 毛利率应在 1%-95% 之间 |
| 客单价 | 必填，> 0，最多两位小数 | 请输入大于 0 的客单价 |
| 回本周期 | 必填，1-60 的整数 | 回本周期应在 1-60 个月之间 |
| 记账金额 | 必填，> 0，最多两位小数 | 请输入大于 0 的金额 |
| 备注 | 选填，最多 50 字 | 备注最多 50 字 |

校验规则：

- 输入阶段可以轻提示，提交阶段必须阻断。
- 阻断时聚焦第一个错误字段。
- 单位必须展示在字段附近。
- 金额统一保留两位小数展示。
- 百分比输入展示为 65%，计算内部可用 0.65。

## 公式规则

基础公式：

```text
每月目标利润 = 前期投入 / 回本周期
月毛利目标 = 每月固定支出 + 每月目标利润
月流水目标 = 月毛利目标 / 毛利率
日流水目标 = 月流水目标 / 每月营业天数
日单量目标 = 日流水目标 / 客单价
日固定成本摊销 = 每月固定支出 / 每月营业天数
今日估算利润 = 今日收入 * 毛利率 - 日固定成本摊销 - 今日其他支出
回本进度 = 累计估算利润 / 前期投入
```

展示规则：

- 金额使用人民币符号。
- 单量向上取整展示，但公式解释中保留原始值。
- 百分比保留 0 或 1 位小数，按场景决定。
- 目标线相关值应在报告、看板、实验室保持一致。

周期展示补充：

- 今日目标 = 日流水目标。
- 本周目标 = 月流水目标 * 7 / 当前月自然天数。
- 本月目标 = 月流水目标。
- 周/月利润估算按周期内每天估算利润相加；无记录日期不主动补收入或支出。
- 投入回收进度 = 累计估算利润 / 前期投入，文案必须解释“已估算回收”和“还差多少”，不使用“保证回本”类表达。

## 风险判断规则

| 风险 | 判断 | 等级 |
|---|---|---|
| 固定成本压力低 | 固定支出 / 月流水目标 < 25% | 低 |
| 固定成本压力中 | 25% <= 固定支出 / 月流水目标 <= 40% | 中 |
| 固定成本压力高 | 固定支出 / 月流水目标 > 40% | 高 |
| 回本周期激进 | 回本周期 <= 6 月 | 中到高 |
| 回本周期常规 | 7-18 月 | 低到中 |
| 回本周期保守 | 19-24 月 | 中 |
| 回本周期过长 | > 24 月 | 中到高 |
| 毛利率偏低 | 低于行业下限 5 个百分点 | 中 |
| 客单价偏乐观 | 高于行业上限 30% | 中 |
| 连续亏损 | 连续 3 天亏损 | 中 |
| 连续严重亏损 | 连续 7 天亏损 | 高 |

风险提示不阻断流程，除非输入本身非法。

## 状态规则

### 加载态

- 首屏加载不超过 1 秒时可使用骨架屏。
- 本地数据读取失败时展示重试和清空数据入口。
- 不使用永久转圈。

### 空状态

- 空状态必须说明原因。
- 空状态必须给出下一步操作。
- 不出现只有图标没有文案的空状态。

### 错误态

- 计算错误时展示“当前参数无法计算，请检查输入”。
- 数据保存失败时保留用户输入。
- 删除失败时不从列表移除。
- 读取异常时不展示错误数据。

### 成功态

记账成功反馈必须包含经营语境：

- 已记录收入 ¥200，今天还差 ¥640 达到回本线。
- 已记录支出 ¥120，今日估算利润降为 ¥260。
- 已保存模型，今日目标已更新为 ¥1,500。

快速记账弹窗反馈规则：

- 保存按钮前应展示当前日期的今日摘要，帮助用户确认本笔记录会进入哪一天。
- 数字键盘的“确定”承担保存动作，金额为空或为 0 时不可产生记录。
- 保存成功后展示稳定反馈区，至少包含本笔记录金额、分类、今日目标差额或今日估算利润。
- 保存成功后必须提供“继续记一笔”和“回看板”两个动作。
- “继续记一笔”清空金额和备注，保留当前日期、当前收入/支出类型，并默认选中该类型第一个分类。
- “回看板”进入今日看板，指标必须按最新记录刷新。

## 编辑和删除规则

### 编辑记录

- 点击最近记录或记账记录页列表进入编辑态。
- 编辑态顶部必须明确提示“正在编辑历史记录”，并提供取消入口。
- 新增和编辑必须复用同一个快速记账弹窗。
- 编辑完成后更新原记录，不新增记录。
- 编辑保存后退出编辑态，回到普通新增态。
- 修改日期时，原日期和新日期的聚合值都需要刷新。

### 删除记录

- 删除前二次确认。
- 删除后看板、趋势、投入回收进度同步回滚。
- 删除操作成功后显示轻提示。

### 修改模型

- 修改模型前展示当前模型。
- 保存后报告、看板、实验室全部使用新基线。
- 历史记账记录不删除。
- 因模型变更导致的历史利润重算，需要明确口径：V1 默认按当前模型重算。

## 实验室规则

- 实验室默认载入当前模型。
- 模拟调整 Tab 用于调整变量并实时看单个方案变化。
- 情景对比 Tab 默认展示当前方案、降压方案、提效方案、压力测试方案。
- 调整参数不直接覆盖模型。
- 对比结果显示调整前和调整后。
- 用户点击“采纳此方案”时才进入模型确认流程。
- 如果调整导致指标变差，也要如实展示。
- 建议文案只解释变化，不承诺改善。

## 隐私与合规规则

- V1 不强制采集手机号、位置、通讯录、相册。
- 经营数据默认本地保存。
- 如启用登录或云同步，必须先补隐私政策和授权说明。
- 免责声明必须在欢迎页、报告页或我的页可访问。
- AI 建议若面向用户展示，必须明确“由模型生成，仅供参考”。
- 营销文案不得承诺收益、回本或盈利。

## 跨端降级规则

| 能力 | 可用时 | 不可用时 |
|---|---|---|
| 分享 | 生成分享卡或分享链接 | 隐藏分享入口 |
| 订阅消息 | 用户授权后提醒记账 | 不展示强提醒能力 |
| 云同步 | 登录后同步 | 使用本地存储 |
| 支付 | 付费模板可购买 | 不展示购买入口 |
| 客服反馈 | 跳转客服 | 使用表单或复制邮箱 |

核心链路不得依赖可选平台能力。
