## 设计图页面清单

设计图展示 8 个核心页面：

1. 欢迎页：品牌、价值说明、开始测算、直接进入。
2. 行业选择页：行业卡片、风险标签、毛利率参考。
3. 开店测算页：前期投入、每月固定支出、营业天数、毛利率、客单价、回本周期。
4. 经营报告页：日流水目标、核心指标、风险评估、经营优先级。
5. 看板页：今日、本周、本月经营状态、投入回收进度、周期趋势、最近记录。
6. 快速记账弹窗：收入/支出切换、日期、金额、数字键盘、分类、可选备注、保存记录。
7. 实验室页：模拟调整、情景对比、调整前后指标、建议提示。
8. 我的页：当前模型、修改参数、重新测算、数据说明、免责声明、反馈、清空数据。

## 主要界面结构参考

### 首启链路

欢迎页 -> 行业选择页 -> 开店测算页 -> 经营报告页 -> 今日看板页

首启链路的目标是尽快产出第一张经营报告，不展示复杂功能总览。

### 日常链路

看板 -> 快速记账弹窗 -> 看板刷新 -> 记录 Tab 管理历史 -> 实验室推演 -> 我的页调整模型

日常链路的目标是让用户持续回到“今天是否达标”的判断。

## 竞品参照维度

本项目不以复制竞品功能为目标，只参考以下维度：

| 类型 | 可参考点 | 需要避开的点 |
|---|---|---|
| 通用记账 App | 快速录入、分类、趋势 | 不要变成个人消费账本 |
| 门店 SaaS | 经营看板、目标、报表 | 不做重后台、库存、CRM |
| 平台经营工具 | 商家经营建议、指标诊断 | 不依赖平台内交易数据 |
| 表格模板 | 测算公式透明 | 不让用户面对复杂表格 |

## 内容和运营参考方向

适合冷启动的内容题材：

- 预算测算：3 万、5 万、10 万能不能开一家店。
- 回本测算：奶茶店、美甲店、咖啡店每天要卖多少。
- 避坑拆解：房租、人工、平台抽佣、损耗如何吃掉利润。
- 新手复盘：开业前 30 天和开业后 30 天该盯哪些数。
- 沙盘推演：客单价涨 5 元、日单量少 10 单、固定成本降 2000 元会怎样。

这些题材应服务产品转化，不应把产品包装成泛创业资讯平台。

## 数据口径参考

V1 统一采用轻量经营测算口径：

```text
每月目标利润 = 前期投入 / 回本周期
月毛利目标 = 每月固定支出 + 每月目标利润
月流水目标 = 月毛利目标 / 毛利率
日流水目标 = 月流水目标 / 每月营业天数
日单量目标 = 日流水目标 / 客单价
今日估算利润 = 今日收入 * 毛利率 - 日固定成本摊销 - 今日其他支出
回本进度 = 累计估算利润 / 前期投入
```

若后续引入平台费率、损耗率、退款率、税费率，应升级为扩展公式：

```text
目标月流水 = 月度目标毛利润 / (毛利率 - 平台费率 - 损耗率 - 退款折让率 - 税费率)
```

## 风险标签参考

| 风险 | 判断线索 | 表达方式 |
|---|---|---|
| 固定成本压力 | 固定支出占月流水目标过高 | 固定支出偏高，容错率较低 |
| 单量压力 | 日单量接近最大接待能力 | 目标接近接待上限，冷启动难度高 |
| 回本周期激进 | 回本周期小于 6 个月 | 目标较激进，适合对比不宜默认 |
| 毛利率异常 | 低于行业参考范围 | 请复核定价、原料或服务成本 |
| 客单价偏乐观 | 高于行业参考范围较多 | 需要验证用户接受度 |
| 连续亏损 | 3 天或 7 天连续亏损 | 建议优先复核固定支出和客流 |
