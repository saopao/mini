# 设计系统

## 设计目标

界面应让新手店主在手机上快速理解经营状态，减少焦虑但不粉饰风险。

设计关键词：

- 清爽
- 克制
- 可信
- 经营导向
- 数据优先
- 行动明确

## 视觉基准

以 `reference/design-reference.png` 为视觉基准：

- 主色使用经营感绿色。
- 页面背景为浅灰或极浅绿。
- 卡片背景以白色为主。
- 指标数字大于说明文字。
- 重要结论使用整块高亮卡片。
- 风险和状态使用颜色标签辅助识别。
- 底部导航固定展示日常核心页面。

## 色彩 Token

| Token | 建议值 | 用途 |
|---|---:|---|
| `color.brand.primary` | `#0F9F5A` | 主按钮、选中态、关键进度 |
| `color.brand.dark` | `#087A43` | 强调文字、按钮按下态 |
| `color.brand.light` | `#EAF8F0` | 成功背景、报告顶部卡片 |
| `color.bg.page` | `#F6F8F7` | 页面背景 |
| `color.bg.card` | `#FFFFFF` | 卡片背景 |
| `color.text.primary` | `#111827` | 主标题、核心数字 |
| `color.text.secondary` | `#4B5563` | 正文、表单值 |
| `color.text.muted` | `#9CA3AF` | 辅助说明、占位符 |
| `color.border` | `#E5E7EB` | 分割线、卡片边框 |
| `color.warning` | `#F59E0B` | 中风险、注意 |
| `color.warning.bg` | `#FFF7E6` | 中风险背景 |
| `color.danger` | `#EF4444` | 高风险、删除 |
| `color.danger.bg` | `#FEF2F2` | 高风险背景 |
| `color.info` | `#2563EB` | 信息提示 |

禁止使用大面积高饱和渐变。可以在欢迎页插画或报告主卡中使用轻微明暗层次，但不得影响可读性。

## 字体层级

| 样式 | 字号 | 字重 | 用途 |
|---|---:|---:|---|
| Page Title | 20-22 | 600 | 页面标题 |
| Section Title | 16-18 | 600 | 模块标题 |
| Metric XL | 32-40 | 700 | 日流水目标、关键结论 |
| Metric L | 24-28 | 700 | 看板核心指标 |
| Body | 14-16 | 400 | 表单、说明、列表 |
| Caption | 12-13 | 400 | 辅助说明、单位、注释 |
| Button | 15-16 | 600 | 主按钮文字 |

原则：

- 核心数字必须有明显层级。
- 不使用过小字号承载关键业务含义。
- 卡片内标题不使用超大字号。
- 文案过长时换行，不压缩字距。

## 间距和圆角

| Token | 建议值 | 用途 |
|---|---:|---|
| `space.1` | 4 | 小间距 |
| `space.2` | 8 | 标签内边距、紧密元素 |
| `space.3` | 12 | 卡片内元素 |
| `space.4` | 16 | 页面主间距 |
| `space.5` | 20 | 模块间距 |
| `space.6` | 24 | 首屏大间距 |
| `radius.sm` | 8 | 标签、输入框 |
| `radius.md` | 12 | 按钮、轻卡片 |
| `radius.lg` | 16 | 信息卡片 |
| `radius.xl` | 20 | 顶部结论卡 |

卡片圆角不宜超过 20。按钮建议 12-16，保持移动端亲和但不幼态。

## 页面框架

### 顶部栏

- 标题居中。
- 返回按钮在左侧。
- 微信胶囊区按平台安全区域处理。
- 除分享、日历等明确功能外，不放多余入口。

### 内容区

- 页面左右边距 16。
- 同类信息用卡片分组。
- 每张卡片只承担一个明确目的。
- 卡片内不再嵌套卡片。
- 数据列表保持扫描效率，不使用过多装饰。

### 底部操作

- 首启流程使用底部固定主按钮。
- 日常页面使用底部导航。
- 表单提交按钮必须在输入完成后保持可见。

### 底部 Tab

V1 固定使用 4 个日常页签：

1. 看板
2. 记账
3. 实验室
4. 我的

欢迎页、行业选择页、开店测算页、经营报告页属于首启和重新测算流程，不放入底部 Tab。重新测算入口放在“我的”页和报告相关入口中。

## 组件规范

### 主按钮

- 高度 48。
- 圆角 14-16。
- 背景使用 `color.brand.primary`。
- 禁用态使用浅灰背景，不只降低透明度。
- 文案使用动词加结果，例如“生成经营报告”“保存记录”。

### 次按钮

- 白底描边。
- 仅用于返回、直接进入、查看报告等次级操作。
- 不与主按钮使用同等视觉重量。

### 行业卡片

内容：

- 行业图标或插画。
- 行业名称。
- 风险等级标签。
- 参考毛利率。

状态：

- 默认：白底、浅边框。
- 选中：绿色边框、浅绿背景、左上角勾选标识。
- 禁用或未开放：灰态，并明确“待开放”。

### 指标卡

内容：

- 指标名称。
- 指标值。
- 单位或说明。
- 可选趋势或状态。

要求：

- 数字优先。
- 单位不要和数字抢层级。
- 负数、亏损、异常必须有明确颜色和文案。

### 表单项

表单行结构：

- 左侧图标或字段名。
- 右侧当前值。
- 可编辑项显示箭头或输入态。
- 单位明确，如元、天、%、月。

输入要求：

- 金额支持两位小数。
- 百分比展示为 65%，存储可为 0.65。
- 必填项为空时在提交阶段提示。
- 越界输入就地提示。

### 风险标签

| 等级 | 色彩 | 文案 |
|---|---|---|
| 低 | 绿色 | 低风险、已达标、健康 |
| 中 | 橙色 | 中高风险、有压力、需关注 |
| 高 | 红色 | 高风险、危险、建议重评 |

标签只表达状态，不承诺结果。

### 图表

V1 图表保持轻量：

- 看板 7 天趋势使用折线图。
- 目标线使用虚线。
- 收支结构可使用横向条形图。
- 数据不足时展示点状趋势或空状态。
- 不做复杂仪表盘和炫技动画。

## 文案语气

文案应像懂经营的助手，不像财务系统。

推荐：

- 今天还差 ¥640 达到回本线。
- 若保持当前客单价，还需要约 26 单。
- 固定支出偏高，容错率较低。
- 该结果仅用于经营测算参考。

避免：

- 净现值、折现率、复式记账等专业术语堆砌。
- 你的经营失败风险极高。
- 保证帮你回本。
- 一定能提升利润。

## 空状态

| 场景 | 文案方向 | 操作 |
|---|---|---|
| 未建模 | 先完成测算，今日目标才有意义 | 去测算 |
| 无记账 | 今天还没有记录，先记一笔收入或支出 | 记一笔 |
| 趋势不足 | 连续记录 2 天后可查看走势 | 补录历史 |
| 实验室无基线 | 需要先保存经营模型才能推演 | 去测算 |
| 我的页无模型 | 暂无当前模型 | 开始测算 |

## 可访问性和适配

- 所有点击目标不小于 44x44。
- 关键颜色状态必须配合文字，不只依赖颜色。
- 重要金额和百分比使用足够对比度。
- iPhone 安全区和 Android 底部导航都要适配。
- 长文字必须换行，不能遮挡按钮或指标。
- 小屏下卡片可纵向堆叠，不压缩为难读网格。

## 动效原则

V1 只使用功能性动效：

- 数字刷新可轻微过渡。
- 保存成功使用轻提示。
- 风险升级可使用一次性高亮。
- 切换收入/支出使用分段控件滑动。

不做复杂动效、滚动视差或装饰性动画。
