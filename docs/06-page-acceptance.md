# 页面验收标准

## 总体验收原则

页面验收以“用户能否完成经营判断”为第一标准，视觉还原和技术实现服务于这个目标。

所有页面必须满足：

- 375px 宽移动端可完整使用。
- 关键操作不依赖横屏。
- 关键指标有来源或解释入口。
- 空状态、加载态、错误态齐全。
- 表单异常有明确提示。
- 不出现收益承诺或绝对化经营结论。
- 数据变更后相关页面同步刷新。

## 欢迎页

### 目标

让用户在 5 秒内理解产品价值，并进入测算流程。

### 必须展示

- 产品名：开店避坑助手。
- 核心价值文案：开店前先算清，开店后每天看清。
- 主按钮：开始测算。
- 次按钮：我已开店，直接进入。
- 本地数据和隐私提示。
- 免责声明入口。

### 验收标准

- 点击“开始测算”进入行业选择页。
- 点击“我已开店，直接进入”时，如果没有模型，应引导完成测算；如果已有模型，进入看板。
- 免责声明可展开或进入说明页。
- 页面无登录阻断。

## 行业选择页

### 目标

让用户选择合适的行业模板，降低后续输入难度。

### 必须展示

- 至少 6 个行业卡片。
- 每张卡展示行业名称、参考毛利率、风险等级。
- 行业模板说明：参数仅供参考，可在后续手动调整。
- 主按钮：下一步。

### 行业建议

| 行业 | 默认风险 | 参考毛利率 |
|---|---|---|
| 奶茶/饮品 | 中等风险 | 60%-70% |
| 咖啡店 | 中等风险 | 65%-75% |
| 小吃快餐 | 中等风险 | 50%-60% |
| 烘焙甜品 | 中等风险 | 60%-70% |
| 美甲美睫 | 中低风险 | 70%-80% |
| 宠物店 | 中等风险 | 45%-55% |
| 便利店 | 较低风险 | 20%-30% |
| 服装零售 | 中等风险 | 40%-55% |

### 验收标准

- 未选择行业时不能进入下一步。
- 选中卡片有明确视觉状态。
- 切换行业后，测算页默认参数同步变化。
- 支持返回欢迎页。

## 开店测算页

### 目标

收集最少经营参数，生成可解释的经营报告。

### 必填字段

- 前期投入。
- 每月固定支出。
- 每月营业天数。
- 行业毛利率。
- 客单价。
- 预期回本周期。

### 可选字段

- 店铺名称。
- 城市。
- 最大日单量。
- 投入拆分。
- 固定支出拆分。

### 验收标准

- 用户可在 1 分钟内完成最小表单。
- 数字输入支持金额、百分比、天数、月数的正确单位。
- 输入变更后即时预估月流水、日流水、日单量。
- 点击“生成经营报告”前执行字段校验。
- 校验失败时定位到对应字段，并展示明确原因。
- 离开页面前如有未保存输入，应提示保存草稿或放弃。

## 经营报告页

### 目标

把测算结果翻译成新手店主能理解和行动的经营目标。

### 必须展示

- 顶部结论卡：每天至少需要的流水和单量。
- 核心指标：月流水目标、日流水目标、日单量目标、回本周期、毛利率。
- 风险评估：固定成本、单量、回本周期、毛利率。
- 经营优先级建议。
- 公式拆解入口。
- 主按钮：保存模型并进入看板。
- 次级入口：去实验室模拟优化。

### 验收标准

- 每个核心指标能追溯到输入字段和公式。
- 客单价缺失时不显示日单量目标，并提示补充。
- 风险标签颜色和文案一致。
- 点击保存后模型持久化，并进入看板。
- 修改参数后重新计算报告。
- 报告中必须出现“不构成投资建议”类说明。

## 今日看板页

### 目标

让用户 10 秒内知道今天是否达标。

### 必须展示

- 今日流水。
- 今日利润估算。
- 目标完成率。
- 回本进度。
- 今天是否达标状态。
- 7 天趋势。
- 最近记录。
- 入口：记一笔、查看报告、去实验室。

### 验收标准

- 无模型时展示引导卡，不展示无意义指标。
- 无记录时指标可显示 0，但需有记账引导。
- 记录新增、编辑、删除后，今日指标即时刷新。
- 趋势少于 2 天时不展示误导性折线。
- 累计利润为负时，回本进度显示负向状态。
- 下拉刷新或重新进入页面后数据一致。

## 快速记账页

### 目标

让用户用 10 秒完成一笔收入或支出记录。

### 必须展示

- 收入/支出分段控件。
- 日期选择。
- 金额输入。
- 快捷金额。
- 分类选择。
- 备注输入。
- 今日摘要。
- 保存按钮。

### 收入分类

- 堂食
- 外卖
- 自提
- 私域
- 其他

### 支出分类

- 房租
- 人工
- 原料
- 水电
- 平台费
- 营销
- 设备
- 其他

### 验收标准

- 默认日期为今天。
- 默认类型为收入。
- 金额必须大于 0。
- 备注可为空，长度建议不超过 50。
- 保存后显示经营反馈，不只显示“保存成功”。
- 保存后更新今日摘要。
- 支持继续记一笔。
- 历史记录可以编辑和删除。

## 实验室页

### 目标

让用户比较调价、控成本、调回本周期等策略对经营压力的影响。

### 必须展示

- 当前方案基线。
- 参数调整区。
- 调整前后对比。
- 变化幅度。
- 经营建议。
- 入口：保存为方案或返回报告。

### 可调参数

- 客单价。
- 日单量。
- 毛利率。
- 固定支出。
- 回本周期。

### 验收标准

- 未建模时不可用，并引导去测算。
- 修改任一参数后实时重算。
- 对比结果必须展示至少 3 个指标：日流水、月利润、回本周期或单量压力。
- 调整值越界时提示，不产生错误结果。
- 建议文案必须基于实际变化，不输出空泛内容。

## 我的页

### 目标

集中管理模型、数据、说明和反馈。

### 必须展示

- 当前店铺模型摘要。
- 查看经营报告。
- 修改基础参数。
- 重新测算。
- 数据说明。
- 免责声明。
- 意见反馈。
- 清空本地数据。

### 验收标准

- 无模型时展示开始测算入口。
- 清空数据必须二次确认。
- 清空后返回无模型状态。
- 修改模型后所有页面同步重算。
- 免责声明和数据说明可访问。
- 不展示未实现的付费、登录或云同步入口，除非已有明确功能。

## 全链路验收

### 新用户链路

1. 打开欢迎页。
2. 点击开始测算。
3. 选择行业。
4. 填写测算参数。
5. 生成经营报告。
6. 保存模型。
7. 进入看板。
8. 记一笔收入。
9. 返回看板看到数据刷新。
10. 进入实验室调整客单价并看到结果变化。

通过标准：

- 全链路无阻断。
- 核心数据前后一致。
- 无登录强制。
- 无空白页。

### 老用户链路

1. 打开小程序进入看板。
2. 查看今日目标和完成率。
3. 记一笔支出。
4. 看板利润下降。
5. 删除该记录。
6. 看板恢复。

通过标准：

- 本地数据持久。
- 增删改后聚合值正确。
- 页面状态及时反馈。
