# 测试用例

## 测试目标

V1 测试重点不是覆盖所有 UI 细节，而是确保经营测算可信、日常链路顺畅、本地数据稳定、异常输入不会产生误导结果。

## 测试范围

必须覆盖：

- 首次使用链路。
- 经营测算公式。
- 报告指标展示。
- 看板聚合。
- 快速记账。
- 实验室推演。
- 本地持久化。
- 空状态。
- 异常输入。
- 数据清空。

暂不覆盖：

- 登录。
- 云同步。
- 支付。
- 多店铺。
- 服务端权限。
- AI 建议。

## 公式基准用例

### TC-FORMULA-001 标准测算

输入：

| 字段 | 值 |
|---|---:|
| 前期投入 | 120000 |
| 每月固定支出 | 18000 |
| 每月营业天数 | 26 |
| 毛利率 | 65% |
| 客单价 | 25 |
| 回本周期 | 12 |

预期：

```text
每月目标利润 = 10000
月毛利目标 = 28000
月流水目标 = 43076.92
日流水目标 = 1656.80
日单量目标 = 66.27，展示约 67 单
日固定成本摊销 = 692.31
```

### TC-FORMULA-002 设计稿示例

输入：

| 字段 | 值 |
|---|---:|
| 前期投入 | 120000 |
| 每月固定支出 | 18000 |
| 每月营业天数 | 26 |
| 毛利率 | 65% |
| 客单价 | 25 |
| 回本周期 | 12 |

说明：

设计稿中报告页展示日流水目标约 ¥1,500、日单量 60 单，是视觉样例。实现时应以公式结果为准，除非产品后续调整固定支出或公式口径。

预期：

- 不为贴合设计稿硬编码结果。
- 报告必须能解释数字来源。

### TC-FORMULA-003 今日利润

基线：

| 字段 | 值 |
|---|---:|
| 今日收入 | 1680 |
| 今日其他支出 | 1148 |
| 毛利率 | 65% |
| 日固定成本摊销 | 692.31 |

预期：

```text
今日估算利润 = 1680 * 0.65 - 692.31 - 1148 = -748.31
```

说明：

如果产品希望展示“今日利润 ¥532”这类视觉稿数字，需要明确另一套口径，例如收入减支出。V1 默认以 `docs/07-interaction-rules.md` 的经营利润估算公式为准。

### TC-FORMULA-004 回本进度

输入：

| 字段 | 值 |
|---|---:|
| 前期投入 | 120000 |
| 累计估算利润 | 45600 |

预期：

```text
回本进度 = 38%
```

## 首次使用链路

### TC-FLOW-001 新用户完成测算

步骤：

1. 打开欢迎页。
2. 点击开始测算。
3. 选择奶茶/饮品。
4. 填写标准测算参数。
5. 点击生成经营报告。
6. 查看报告。
7. 点击保存模型并进入看板。

预期：

- 页面按顺序跳转。
- 报告展示月流水、日流水、日单量、风险评估。
- 保存后看板展示当前模型目标。
- 关闭并重新打开后仍存在模型。

### TC-FLOW-002 已开店直接进入

前置：

- 本地无模型。

步骤：

1. 欢迎页点击“我已开店，直接进入”。

预期：

- 不进入空看板。
- 展示需要先完成测算的引导。

### TC-FLOW-003 老用户默认看板

前置：

- 本地已有模型。

步骤：

1. 打开小程序。

预期：

- 默认进入今日看板或快速可见今日看板入口。
- 今日目标与保存模型一致。

## 看板用例

### TC-DASH-001 无模型

前置：

- 清空本地数据。

步骤：

1. 进入看板。

预期：

- 展示建模引导。
- 不展示 0 目标造成误导。

### TC-DASH-002 无记录

前置：

- 已保存模型，无记账记录。

预期：

- 今日流水为 0。
- 今日利润按口径展示，或明确暂无记录。
- 显示记一笔入口。

### TC-DASH-003 新增收入后刷新

步骤：

1. 进入记账页。
2. 新增收入 200。
3. 返回看板。

预期：

- 今日流水增加 200。
- 今日完成率更新。
- 最近记录出现该收入。

### TC-DASH-004 删除记录后回滚

步骤：

1. 删除 TC-DASH-003 的收入。
2. 返回看板。

预期：

- 今日流水回滚。
- 最近记录移除。
- 趋势和回本进度同步回滚。
